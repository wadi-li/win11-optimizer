Почему 16 ГБ ОЗУ на T14S не хватает и как работает лимит выделенной памяти (Commit Limit) Текущий pagefile.sys: жёстко задан 8 192 МБ

В реестре вашего ноутбука (HKLM\...\Memory Management\PagingFiles) сейчас прописано жёсткое ограничение: c:\pagefile.sys 8192 8192 (ровно 8 ГБ). В 64-битной Windows 11 26H2 действует строгая формула диспетчера виртуальной памяти: Commit Limit (24 328 МБ) = Видимое ОЗУ (16 136 МБ) + Файл подкачки (8 192 МБ).

Главный секрет нехватки памяти при распаянных 16 ГБ

Программы САПР (Altium Designer, AutoCAD, DipTrace с 3D-моделями STEP), браузеры и системные службы запрашивают у ядра Windows гарантированный резерв виртуальной памяти (Private Commit Charge). Даже если физическое ОЗУ занято всего на 75% (за счёт сжатия Memory Compression, которое сейчас держит 1 215.1 МБ), как только сумма Committed Bytes упирается в потолок 24 328 МБ, Windows выдаёт ошибку нехватки памяти и аварийно закрывает вкладки или САПР!
Прямо сейчас в спокойном состоянии на вашем T14S уже выделено 14 180 МБ Commit (из них 1 662.7 МБ зарезервировал один только AdGuard, 1 300.1 МБ — 6 процессов TheBat64, 770.7 МБ — AdGuard VPN, 504.1 МБ — OneDrive, 500.2 МБ — Grammarly + WebView2). До жёсткого потолка остаётся всего 10.1 ГБ!

Инженерное решение для диска C:\ (NVMe 930 ГБ, свободно 482.9 ГБ)

1. Очистка фонового резерва (Вкладка 2): Выгрузка фоновых пожирателей (AdGuard VPN, Grammarly+WebView2, Autodesk Access, Phone Link, Виджеты, Intel DSA) мгновенно освобождает ~3.7 ГБ Commit Charge и ~2.9 ГБ физического ОЗУ.
2. Расширение pagefile.sys до 16 384 МБ (Исходный) — 24 576 МБ (Максимальный): За счёт установки исходного размера 16 384 МБ (16 ГБ) файл подкачки выделяется одним непрерывным блоком на NVMe SSD без фрагментации, а общий лимит Commit Limit возрастает с 24.3 ГБ до 32.5–40.5 ГБ! При наличии 482.9 ГБ свободного места на диске C: это даёт абсолютный запас прочности для тяжёлых САПР.

2. Уникальное преимущество вашего ThinkPad T14s Gen 1 (BIOS N2YET49W): возврат аппаратного сна S3!

Сейчас вывод powercfg /a на вашем T14S показывает:
Standby (S0 Low Power Idle) Network Connected — Включено
Standby (S3) — Прошивка не поддерживает этот режим.
В режиме S0 Network Connected ноутбук во сне продолжает поддерживать Wi-Fi, принимать пакеты и будить процессор, теряя по 10–25% заряда за ночь.
Но в Lenovo ThinkPad T14s Gen 1 (в отличие от более новых ноутбуков!) в BIOS есть штатный переключатель аппаратного сна S3:
При перезагрузке нажмите F1 (вход в BIOS Setup) → Config → Power → Sleep State и переключите значение с Windows 10 / Windows 11 на Linux (затем F10 Save & Exit). После этого прошивка N2YET49W включает классический глубокий аппаратный сон S3 (Suspend-to-RAM), где процессор и Wi-Fi полностью обесточены, а питание подаётся только на микросхемы ОЗУ (расход падает до <0.3% в час!).
